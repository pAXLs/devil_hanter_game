# ⚔️ Devil Hunter (2.5D Action RPG)

A dark fantasy 2.5D Action RPG / Hack'n'Slash built with **Godot Engine 4** (GL Compatibility).
Inspired by Diablo 3/4, Hades, and Chronicon.

## 🕹️ Controls
* **WASD** — Move character (grounded, responsive movement)
* **Mouse Cursor** — 360° Aiming / Facing direction
* **Space** — Dodge Roll / Dash (with invulnerability frames)
* **Left Mouse Button (LMB)** — Primary Sword Slash (115° cone in front)
* **R** — Ultimate: Earthshaker (massive AoE slam, screen shake, knockback)

## 🛠️ Tech Stack & Architecture
* **Engine:** Godot Engine 4.7.2
* **Renderer:** GL Compatibility (Universal OpenGL 3 support)
* **Perspective:** 2.5D Low-Poly 3D with isometric camera
* **Networking Foundation:** Decoupled game state for seamless future co-op / LAN multiplayer.

## 🚀 Running the Project
1. Open Godot Engine 4.
2. Click **Import** and select this repository folder.
3. Press **F5** to play!
